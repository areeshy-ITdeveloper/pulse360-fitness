## 🚀 Key Features

* **5+ Dynamic Pages:** Full routing using `react-router-dom` (`Home`, `About Us`, `Services & Programs`, `Transformation Gallery`, `Contact Us`).
* **Telemetry Dispatch System:** Functional footer newsletter capture integrated with browser `localStorage` state management.
* **Interactive Pass Allotment & Lab Booking:** Custom popups and modals with smooth transitions for immediate user engagement.
* **High-Contrast Dark Aesthetics:** Cyberpunk-inspired luxury performance UI tuned with high-visibility neon accents (`#CCFF00`).
* **Responsive Layout:** Optimized for high-definition desktop viewports down to handheld mobile devices.
* **Scroll Management:** Built-in auto scroll-to-top handler on page navigation.

## 📝 Design Decisions & Future Enhancements

For the Pulse360 web application, I selected a sleek, dark-mode visual architecture coupled with high-contrast neon accents to evoke a high-performance, futuristic biometric fitness experience. The component layout prioritizes responsive scannability and high user engagement, utilizing custom interactive modal dialogues for immediate pass allotment and lab assessment bookings. Functional state management ensures seamless UI transitions without full page reloads, storing dynamic user entries in persistent browser storage for real-time interactivity. For future improvements, I plan to integrate a full backend authentication system with Node.js and MongoDB to save real user profiles permanently. Additionally, I aim to implement full database integration for live slot booking scheduling and automated email confirmation notifications.
